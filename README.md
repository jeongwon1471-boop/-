# 식권 관리 v2
직원과 식당은 관리자가 추가/사용 중지합니다. 직원은 본인 이름을 고르고 식당별 +/− 버튼으로 입력합니다. 날짜는 자동으로 오늘 날짜가 기록되며 월별 집계 및 CSV를 제공합니다.

## Render
GitHub 저장소 **루트**에 package.json, server.js, public 폴더를 업로드합니다. ZIP 자체를 올리지 마세요.
- Runtime: Node
- Build command: npm install
- Start command: npm start
- 환경변수 NODE_VERSION=22.16.0
- 환경변수 ADMIN_PASSWORD=충분히 긴 본인만 아는 비밀번호 (4자리 비밀번호는 권장하지 않음)
- 선택 환경변수 DATA_DIR: 영구 디스크 마운트 경로

**중요:** Render 무료 Web Service의 로컬 파일은 재배포·재시작 시 사라질 수 있습니다. SQLite DB가 로컬에 저장되므로 무료 플랜만으로 실제 한 달치 식권 기록의 영구 보존을 보장할 수 없습니다. 운영 전 영구 디스크가 가능한 유료 플랜 또는 외부 영구 DB로 전환해야 합니다.

**주의:** 기존 v1 DB의 `people` 테이블은 유지되지만 v1의 `usage` 데이터는 이 버전의 식당별 집계에 포함되지 않습니다. v1 기록을 옮기려면 어느 식당에 해당하는지 정해 별도로 이전해야 합니다. 이름만 선택하는 방식이므로 다른 직원이 대신 입력할 수 있습니다.
